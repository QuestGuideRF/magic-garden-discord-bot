## 📖 Описание

Автоматизированный Python-бот с **красивым графическим интерфейсом**, который собирает урожай на сетке 10×10 участков по **змейке**, автоматически продаёт урожай при заполнении инвентаря и отслеживает подробную статистику **в реальном времени**.

---

## 🚀 Быстрый старт (Для всех!)

Это самый простой способ запустить бота — **никаких навыков программирования не требуется!**

### Шаг 1: Скачайте бота

1. Скачайте архив
2. Распакуйте скачанный файл в отдельную папку на вашем компьютере

### Шаг 2: Проверьте/Обновите скриншот авто-продажи

Бот поставляется с изображением по умолчанию `inventory_full.png`, расположенным в папке `src/images/`. Это изображение помогает боту определить, когда ваш игровой инвентарь заполнен.

**Большинству пользователей НЕ нужно делать этот шаг.** Предоставленное изображение должно работать для стандартных настроек игры.

**Однако, если бот не определяет ваш инвентарь правильно:**

1. В игре заполните инвентарь, чтобы появилось всплывающее окно "Inventory Full"
2. Нажмите **`Windows Key + Shift + S`**, чтобы открыть инструмент "Ножницы"
3. Обведите область и захватите **только всплывающее сообщение**
4. Сохраните этот новый скриншот как `inventory_full.png` в папке `src/images/`, заменив существующий

Это гарантирует, что бот имеет правильное изображение для вашего конкретного разрешения игры и интерфейса.

### Шаг 3: Запустите бота!

1. Дважды щёлкните `MagicGardenBot.exe`, чтобы запустить бота
2. Если Windows показывает предупреждение безопасности, нажмите **"Подробнее"** → **"Выполнить в любом случае"**. Это нормально для новых приложений
3. Расположите вашего игрового персонажа на левом верхнем участке сада
4. Нажмите большую зелёную кнопку **"▶ START"** в окне бота
5. У вас есть 3 секунды, чтобы переключиться обратно в окно игры

Бот начнёт собирать урожай! Вы можете отслеживать его прогресс в графическом интерфейсе. Чтобы остановить его, нажмите кнопку **"⏹ STOP"** или переместите мышь в самый левый верхний угол экрана.

## ⚙️ Конфигурация

Все настройки можно изменить непосредственно в графическом интерфейсе. Они автоматически сохраняются в файл `bot_config.json` в домашней директории вашего пользователя.

| Настройка | Описание | По умолчанию |
|-----------|----------|--------------|
| `GRID_SIZE` | Размер сетки сада (например, 10 для сетки 10×10) | 10 |
| `HARVEST_COUNT` | Сколько раз нажимать клавишу сбора урожая на каждом участке | 5 |
| `MOVE_DELAY` | Задержка между каждым шагом (в секундах). Увеличьте, если движение рывками. | 0.15 |
| `HARVEST_DELAY` | Задержка между каждым действием сбора урожая (в секундах) | 0.1 |
| `LOOP_COOLDOWN` | Сколько ждать после завершения полного цикла сбора урожая (в секундах) | 2 |

## ⚠️ Решение проблем

### Бот не определяет "Inventory Full"

- Переснимите ваш скриншот `inventory_full.png`. Убедитесь, что это чёткий, плотно обрезанный всплывающий диалог
- Убедитесь, что всплывающее окно в игре выглядит точно так же, как когда вы делали скриншот

### Движение слишком быстрое/медленное

- Отрегулируйте настройки `MOVE_DELAY` и `HARVEST_DELAY` в графическом интерфейсе
- Нажмите "💾 Save Config", чтобы применить изменения

### Бот останавливается неожиданно

- Проверьте журнал активности в графическом интерфейсе на наличие красных сообщений об ошибках
- Убедитесь, что окно игры остаётся активным, сфокусированным окном

### 🏗️ Сборка исполняемого файла

Если вы хотите собрать приложение в файл `.exe` самостоятельно, вам понадобится `pyinstaller`.

1. **Установите PyInstaller:**
   ```bash
   pip install pyinstaller
   ```

2. **Соберите исполняемый файл:**
   Выполните эту команду из корневой папки проекта:
   ```bash
   pyinstaller --onefile --windowed --icon=src/bot_icon.ico --name="MagicGardenBot" src/MagicGardenBot.py
   ```
   Готовый `.exe` файл будет расположен в папке `dist`.
